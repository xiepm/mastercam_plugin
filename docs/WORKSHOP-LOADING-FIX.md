# 工艺助手加载修复 · 2027.11.10.1

“复杂孔自动工序”此前可能弹出 `ReflectionTypeLoadException`，提示找不到 `AdvancedDrill2027 0.1.2.0` 和 `OperationTools2027 1.0.3.0`。这两个文件已经安装，但分处独立插件目录；Mastercam 在调用目标入口前枚举程序集类型，原入口没有配置跨目录依赖解析。

Workshop 2.8.1 在转发相关命令前核对依赖文件、程序集版本和已加载路径。启动器 1.0.1 同时注册三个套件程序集的解析位置，使直接入口和 MP 对 Porsche 的传递引用也能解析。缺文件、版本错误或已有其他路径的同名程序集会给出具体修复提示。

## 更新

完整解压修复包，正常退出 Mastercam，运行 `Install.cmd`，再启动 Mastercam。当前维护的电脑已完成安装和重启。可用 `Verify.cmd` 检查本机文件和启动项。
