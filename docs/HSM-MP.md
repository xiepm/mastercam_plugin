# HSM 与 MP 新增功能

本次补入独立重构的实际加工和几何功能。原版 HSM 完整内核与 Moldplus 2027 安装包没有混用旧版本替代。

## HSM 加工

选择一项二维轮廓或挖槽参考工序，使用其完整单闭合平面边界和机床/坐标设置，指定已有平底刀、切削参数和高度后，新建真实 `PocketOperation`。支持 HighSpeed 摆线、恒定重叠螺旋、TrueSpiral，以及螺旋/斜插入刀。

创建后重新读取刀具、链、策略和参数；默认待重算且关闭输出。点击“计算本批挖槽”才重算，点击“回滚本批挖槽”删除该会话创建的工序。后续人工编辑会阻止盲目回滚。源工序、刀具与几何保留。

当前只支持单闭合平面边界，不含岛屿/开放挖槽、Dynamic Mill/OptiRough、三维自适应内核、残料模型、五轴、碰撞判定或旧 HSM 工序格式转换。HighSpeed 是公开 API 的真实策略，不表示已复制原厂 HSM 全部算法。

宿主测试包含三种策略的创建回读、高速摆线与恒定重叠螺旋的原生计算、故障注入清理及显式回滚。计算成功不等于刀路无碰撞或可直接上机；仍需按机床和零件进行正常仿真。

## MP 高级几何

- **任意平面截面**：按实体导出世界坐标 STL，求平面交线，生成可编辑线段，分析闭合环及面积。
- **平行切片**：指定首平面、方向、间距、数量，逐实体逐层生成截面。
- **网格拔模角分析**：由三角片绕序法向与拔模方向计算角度和面积，输出报告及 CSV。
- **网格分模准备**：提取相邻三角片拔模分类改变的边。
- **网格法线箭头**：生成可编辑、有方向的彩色箭头，控制采样数量。

这些功能基于有公差的三角网格，未实现精确 B-rep 求交、NURBS UV 编辑、曲面延伸修剪缝合、芯腔布尔分离、自动电极。负角区不等于倒扣；分区交界边不等于经过工艺验证的模具分模线。多个实体的截面分别保留，不自动做布尔并集。

只修改本模块新建的结果线，保留源实体。创建和回滚均按精确 ID、端点、属性与时间戳核对；源对象或结果被修改后拒绝盲目删除。回滚仅适用于当前会话。网格选择保护依赖已冻结的 Porsche 模块和匹配的 Mastercam 构建，详见 [兼容性](COMPATIBILITY.md)。

实际测试结果、DLL 哈希与验收范围见 [验证记录](../validation/README.md)。
