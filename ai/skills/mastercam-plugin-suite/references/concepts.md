# 插件术语与选择依据

| 术语 | 实际含义与 AI 应核对的内容 |
|---|---|
| 工序 ID / 刀路树顺序 | ID 是数据库标识，树上第几道不一定等于 ID；先读 `mc_inspect`。 |
| ToolSlot / Number / H-D | 槽号是工具内部索引，刀号是输出编号，长度/直径补偿号是另外两个字段。不得互换。 |
| World / WCS / CPlane / TPlane | 世界坐标、工件坐标、构图面、刀具平面分别处理。MP 平面参数采用 world；工序深度及 HSM 高度采用 TPlane。非零原点转换必须包含平移。 |
| 绝对深度 / 增量深度 | `Depth` 的解释由 `Incremental` 决定；深度有关联图素时，必须明确是否允许解除关联。 |
| 进给模式 | 每分与每转数值不同；当前操作工具不会自动转换。`ConfirmOriginalFeedMode`/`ReviewedCuttingData` 表示用户数据与宿主模式已核对。 |
| HighSpeed / 摆线 | 这里是 API29 原生 Pocket 策略，非完整商业 HSM、Dynamic Mill 或 OptiRough。 |
| 投影轮廓 / 体积清料 | 保时捷的实体投影可以产生凹边界、内环与分离边界；二维粗精倒角不等同三维清除任意实体周围材料。 |
| 串连 Chain[] | 托管数组还引用原生后继链；过滤共享数组不保证截断原生列表。必须使用完整原数组或独立构造的列表。MCP HSM 只读取参考工序的完整单链。 |
| 网格截面 / 精确曲面 | MP 新功能基于 STL 三角片，公差影响结果；不承诺精确 B-rep 或 NURBS 截面。多个实体分别计算。 |
| 拔模负角 / 倒扣 | 绕序法向的负角并不证明存在遮挡倒扣。分区交界边也不等于可直接使用的模具分模线。 |
| 装刀长度 | Information/Reach 给出刀具平面轴向下界，未检查刀柄、夹具或机床碰撞。 |
| 回滚 / Undo | 本套件使用记录的原值或自有 ID 显式恢复。不能把 CancelTransaction 当作已完成恢复。旧会话的 JSON 不能重建有效 native 回滚句柄。 |
| 已安装 / 已加载 / 已验证 | 文件存在、入口打开、参数回读、原生计算、仿真和生产验收是不同层次；按证据分别报告。 |

选择流程：工序参数用 OperationTools；实体投影/副本补孔/复杂孔流程查 Porsche；单闭合边界挖槽用 HSM；网格截面与拔模分析用 MPRebuild；原生曲面选择/法向/直边查 MPDesign；库、报表、导出、草绘等查对应 X+ 重建模块。CIMCO 用于其已安装的仿真界面，当前 MCP 不声称自动返回其仿真判定。
