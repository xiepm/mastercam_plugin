## 2027.10.29.3 历史范围

当时发布适配层为 1.3.0.0。MP/X+ 新增 18 类动作，合计 28 类、12 个 MCP 工具；[本轮验收](geometry-native-acceptance.json) 列出每个实际用例、构建版本、原始收据哈希、失败修正与清理结果。34 组业务用例覆盖 11 种几何副本编辑，并检查非零旋转平面的草图工序刀路最低点、原对象保护和回滚。全量测试与最后增补发生在不同构建，具体范围逐一标明，未将历史测试写成最终 DLL 的全量重跑。

两种交互面板已实际观察打开，并验证面板打开时拒绝新的原生编辑。另六个固定入口核对 FT 路由，尚未在本轮逐项交互验收。排队回执与窗口打开、业务成功是三个不同结果。

测试最终保留原 57 个几何、13 个工序、11 个刀具槽、12 个平面及原选择，删除本轮自有对象。初次失败的旧 STL 选择路径曾修改测试副本中四个原有参数化实体的时间戳，此事实保留于摘要；修复后的连续回归按其入口基线核对全部几何记录一致。法向/NCI 回滚只承诺原值，不能泛化为全部数据库时间戳恢复。

离线通过 34 项 Python 测试、5 项生产 PreviewGuard 测试、2,278 项核心安装包检查及 Skill 校验。295 个业务载荷文件未改，CIMCO 未改。本轮原始请求、响应、历史失败、UI 文本和夹具证据保存在验证电脑的私有工作区；公开摘要绑定 SHA256，不分发用户零件、私人配置或日志路径。
